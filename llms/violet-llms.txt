- [Enrollment](https://docs.violet.co/for-developers/data-processing/enrollment.md): An enrollment takes place when a user enrolls a VioletID the first time a user want to perform a compliant on-chain transaction that requires a Violet credential.
- [Transaction Authorization](https://docs.violet.co/for-developers/data-processing/transaction-authorization.md): A transaction authorization takes place every time a user want to perform a compliant on-chain transaction that requires a Violet credential.
- [Daily Sanction List Checks](https://docs.violet.co/for-developers/data-processing/daily-sanction-list-checks.md): Violet checks every day if any holder of a VioletID got listed on a US relevant section list.
- [Login Self-Service Portal](https://docs.violet.co/for-developers/data-processing/login-self-service-portal.md): This login process takes place when a holder of a VioletID want to see or change his own data in the our Self-Service Portal.
- [Subpoena](https://docs.violet.co/for-developers/data-processing/subpoena.md): The subpoena process takes place if Violet receives a subpoena  from a court, regulatory body or regulated financial institution under Violet compliance
